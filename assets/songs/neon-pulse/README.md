# 霓虹脉冲 / Neon Pulse

这首演示音乐和三档谱面由本项目的 `tools/generate_demo.py` 原创生成，没有使用第三方音频采样、现成歌曲或外部旋律素材。音频采用基础正弦波、包络和确定性的合成打击声制作，项目内可自由使用、修改和随程序分发。

- 时长：36 秒，120 BPM，4/4 拍。
- 格式：44.1kHz、16-bit、立体声 PCM WAV。
- 谱面从音乐第 3 秒开始，按半拍或整拍编排，尾部预留超过新版 220ms 的判定窗口。
- Easy / Normal / Hard 分别采用 2200 / 1800 / 1400ms 接近时间；三份独立谱面均包含单点、长按、连锁节点及同时键，困难谱包含三押。
- 判定单元数量依次为 68 / 84 / 136；每一条长按只计算一个单元，同时键每个轨道成员各计算一个。

在仓库根目录运行以下命令即可确定性重建 WAV、曲目索引和三份 JSON，无需安装 Python 第三方库：

```powershell
python tools/generate_demo.py
```

WAV 是合成演示曲，目的在于提供合法且可核验节拍的游戏资源；后续加入其他音乐时，应另行记录音频来源和分发许可。
