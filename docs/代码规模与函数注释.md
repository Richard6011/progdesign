## 注释覆盖与校验

- 应用 C 有 129 个函数，Python 有 17 个函数，合计 **146 个命名函数**均有中文详细注释。
- 77 个头文件接口声明也补充了功能、返回值及实现定位。
- 函数定义说明用途、参数和单位、返回或输出、关键步骤，以及适用的失败、生命周期、所有权或状态约束。
- C 与注释前逐文件比较：去除注释与空白后的词法 token 完全相同。
- Python 与注释前比较：仅忽略函数文档字符串后，抽象语法树完全相同。
- 已使用 VS Code“程序设计”配置对应的 MinGW 13.1、CMake 和 Ninja 完成 Release 构建。
- Python 生成器仅做语法与逻辑结构比对，本次没有重新生成或覆盖歌曲资源。

### src/main.c

- `app_run` 初始化应用，处理输入、网络、游戏和绘制，最后释放资源。
- `update_network` 推进网络收发，让客人加载房主选择，并处理断线和比分状态。
- `update_game` 使用本地音乐时间推进演奏。联机时更新累计分并在完赛时发送最终分。
- `save_result` 保存本机成绩。联机时需要本机完赛并已收到对手最终分。
- `action` 和 `input` 处理页面动作、文本输入和游戏按键。

### src/network.c

- 初始化 Winsock 并建立非阻塞 IPv4 TCP 连接。房主监听和接入客人，客人连接指定地址和端口。
- 按已发送字节数推进发送缓冲。接收端保留不完整的消息，积累到一整条后处理。
- 交换昵称、房主选择的曲目和难度、当前与最终比分以及退出通知。
- 处理主动退出、连接失败和断线，释放监听 socket 和对端连接。
