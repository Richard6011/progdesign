## 注释覆盖与校验

- 应用 C/C++：143 个函数；测试：14 个；Python：17 个，合计 **174 个命名函数**均有中文详细注释。
- 77 个头文件接口声明也补充了功能、返回值及实现定位。
- 函数定义说明用途、参数和单位、返回或输出、关键步骤，以及适用的失败、生命周期、所有权或状态约束。
- C/C++ 与注释前逐文件比较：去除注释与空白后的词法 token 完全相同。
- Python 与注释前比较：仅忽略函数文档字符串后，抽象语法树完全相同。
- 已使用 VS Code“程序设计”配置对应的 MinGW 13.1、CMake 和 Ninja 完成 Release 构建。
- 现有回归套件全部通过，共 **262 条断言**，包含六份谱面满分回放、UTF-8 存储、真实 WAV 播放/暂停/恢复，以及真实 TCP 两轮对战和再来一局。
- Python 生成器仅做语法与逻辑结构比对，本次没有重新生成或覆盖歌曲资源。
