# 音符碰撞：快速开始与联机

## 开始玩

解压整个压缩包，进入解压后的顶层文件夹，双击其中的 `NoteCollision.exe`。

1. 点击“开始游戏”，填写1—16个字符的昵称。
2. 模式选“单人”，曲目选择“小星星”，先选 Easy 难度，点击“开始演奏”。
3. D、F、J、K 对应从左到右四条轨道。在音符到判定线时按键；长条音符一直按到尾部。
4. 单人按 Esc 暂停，再按 Esc 或点“继续”恢复；有活动长按时先重新按住对应键。
5. 正常完成整曲后自动保存，返回主页可以查看对应难度排行榜。

新版击打判定已放宽：Perfect ±90ms、Great ±150ms、Good ±220ms（规则版本2，`rulesVersion="2"`）。单人、联机及三档难度共用该窗口，难度区别来自音符排列和下落速度。《小星星》约33.8秒，Easy以主旋律为主，共43个判定单元；熟悉后可切换Normal、Hard或《霓虹脉冲》。

## 把程序发给别人

将 `*-Windows-x64.zip` 发给对方。对方完整解压后进入压缩包生成的顶层文件夹，双击其中的 `NoteCollision.exe` 即可；无需安装 Qt、VS Code 或编译工具。

必须保留整个文件夹中的 DLL、assets、platforms、multimedia 等文件。不要只发送或移动 exe，也不要直接在压缩包内运行。两端使用同一份压缩包，以保证歌曲、谱面和规则一致。

## 两人联机

当前支持两台 Windows 64 位电脑在同一局域网内联机，例如连接同一个路由器的 Wi-Fi 或网线。

1. 双方运行程序，点击“开始游戏”，分别填写昵称，模式选“双人联机”，进入房间页面。
2. 房主点击“创建房间”，默认端口 `38765`。创建时无需填写“房主 IPv4”。
3. 房间页会显示房主的“局域网 IPv4”。房主把这个地址和端口告诉对方。
4. 客人在“房主 IPv4”中填写房主给出的地址，端口保持一致，点击“加入房间”。例如房主为 `192.168.1.100`，客人就输入这个地址。不要输入 `127.0.0.1`，它只指向客人自己的电脑。
5. 房主选择曲目和难度，等待双方音频预加载及资源校验完成，然后双方点“准备”。
6. 房主点击“房主开始”。倒计时之后双方用各自电脑的 D/F/J/K 演奏。
7. 完成后等待最终成绩确认，两端各自自动保存本方成绩。同分为平局。返回房间后重新准备，可以再次开始。

房主修改曲目或难度，会取消双方的准备，需要重新准备。联机倒计时、演奏和等待结果时请保持游戏窗口处于前台；切换到别的窗口、按 Esc、主动退出或断线都会中止当前未确认对局。联机没有暂停。

## 连不上时

- 如果 Windows 弹出防火墙询问，在自己信任的局域网允许 `NoteCollision.exe` 通过“专用网络”。如已经点过拒绝，可在 Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙，允许该程序。
- 确认两台电脑连接同一个局域网，客人填的是房主当前网卡的局域网 IPv4，端口都是 `38765`。有多网卡时，选与双方所用路由器对应的地址。
- 访客 Wi-Fi 或开启设备隔离的网络可能禁止电脑互相访问，换到可互访的网络。
- 若提示端口被占用，房主换一个端口后重建房间，客人也填写新端口。
- 若提示资源不一致，双方重新解压并运行同一份发布包。

## 数据与验证范围

本次新版首次读取已识别的旧版成绩和设置时会重置，从空排行榜、默认设置开始，不保留或迁移旧数据；新版产生的数据此后正常保存。损坏文件或未知未来版本会保留并提示。新成绩、设置保存在各自电脑的 `%APPDATA%/NoteCollision/音符碰撞`。联机双方都需要更新到这份含《小星星》和规则版本2的新版包。

已在开发机完成独立运行包检查和本机双客户端整曲联机。两台实体电脑的网络、声卡同步与实际键盘组合仍需实测。
