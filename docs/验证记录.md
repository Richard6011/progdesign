## 验证边界

自动回放验证判定与状态，不等同于人手节奏表现。localhost 测试不证明两台电脑实际声卡 / 播放设备的起播延迟。实体双机、不同显示缩放、声卡延迟以及键盘双押 / 三押仍需使用者实测。
